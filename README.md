# LangChain Learning Projects

This repository is a simple starter project for learning LangChain by building small code snippets and mini projects.

## Project Purpose

The goal of this workspace is to:
- explore LangChain basics
- practice small examples and experiments
- build simple projects while learning

## Current Files

- main.py: a basic Python entry point for testing simple LangChain-related ideas
- pyproject.toml: project dependencies and package configuration

## Setup

Make sure you have Python 3.12 or newer installed and that uv is installed.

Create and activate the environment with uv:

```bash
uv venv
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
uv venv
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
uv sync
```

## Run the Project

```bash
uv run python main.py
```

## Notes

This project is intentionally simple and meant for learning, experimentation, and growing your LangChain skills over time.
